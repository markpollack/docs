This page builds one experiment end to end: a one-item dataset, an agent, a jury, and the result. The agent here edits the workspace directly so the example runs offline; a real invoker calls an agent at that point. Both programs below were compiled and run, each with a negative control.

## Prerequisites

- Java 21+
- Maven (the project includes `./mvnw`)

## Concepts

## Step 1: Create a Dataset

A dataset is a directory with a manifest and per-item directories:

```
my-dataset/
├── dataset.json
└── items/
    └── RENAME-001/
        ├── item.json
        ├── before/
        │   └── src/main/java/com/example/Person.java
        └── reference/
            └── src/main/java/com/example/Person.java
```

**dataset.json** — the manifest:

```json
{
  "schemaVersion": 1,
  "name": "rename-field",
  "version": "1.0.0",
  "description": "Field rename tasks",
  "items": [
    {
      "id": "RENAME-001",
      "slug": "simple-rename",
      "path": "items/RENAME-001",
      "bucket": "A",
      "taskType": "rename-field",
      "status": "active"
    }
  ]
}
```

**item.json** — per-item metadata:

```json
{
  "schemaVersion": 1,
  "id": "RENAME-001",
  "slug": "simple-rename",
  "developerTask": "Rename the field 'name' to 'fullName' in Person.java and update all references",
  "taskType": "rename-field",
  "bucket": "A",
  "noChange": false,
  "knowledgeRefs": [],
  "tags": ["rename", "simple"],
  "status": "active"
}
```

The `before/` directory is the starting state. The `reference/` directory is the correct answer. The agent never sees the reference — it's used by judges for comparison.

The two `Person.java` files:

`my-dataset/items/RENAME-001/before/src/main/java/com/example/Person.java`

```java
package com.example;

public class Person {

    private final String name;

    public Person(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }
}
```

`my-dataset/items/RENAME-001/reference/src/main/java/com/example/Person.java` is the same file with `fullName` for `name` and `getFullName` for `getName`.

The dataset format is the same on 0.9.0 and on main.

**`src/main/java/com/example/experiment/GettingStarted.java`** — in 0.9.0 one jury serves every item, and a judge reads the item's workspace from its `JudgmentContext`:

```java
package com.example.experiment;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.time.Duration;
import java.util.List;

import io.github.markpollack.experiment.agent.AgentInvoker;
import io.github.markpollack.experiment.agent.InvocationResult;
import io.github.markpollack.experiment.dataset.FileSystemDatasetManager;
import io.github.markpollack.experiment.result.ExperimentResult;
import io.github.markpollack.experiment.runner.AgentExperiment;
import io.github.markpollack.experiment.runner.ExperimentConfig;
import io.github.markpollack.experiment.store.FileSystemResultStore;
import io.github.markpollack.judge.Judge;
import io.github.markpollack.judge.jury.ConsensusStrategy;
import io.github.markpollack.judge.jury.Jury;
import io.github.markpollack.judge.jury.SimpleJury;
import io.github.markpollack.judge.result.Judgment;

public class GettingStarted {

    public static void main(String[] args) {
        Path results = Path.of("target/experiment");

        // The agent under test. This one edits the workspace directly so the example
        // runs offline; a real invoker calls an agent here.
        AgentInvoker agent = context -> {
            Path person = context.workspacePath().resolve("src/main/java/com/example/Person.java");
            try {
                String source = Files.readString(person);
                Files.writeString(person, source.replace("getName", "getFullName").replace("name", "fullName"));
            }
            catch (IOException e) {
                return InvocationResult.error(e.getMessage(), context.metadata());
            }
            return InvocationResult.completed(List.of(), 0, 0, 0, 0.0, 0, null, context.metadata());
        };

        ExperimentConfig config = ExperimentConfig.builder()
            .experimentName("rename-field-v1")
            .datasetDir(Path.of("my-dataset"))
            .model("offline-example")
            .promptTemplate("{{task}}")
            .perItemTimeout(Duration.ofMinutes(2))
            .outputDir(results.resolve("workspaces"))
            .build();

        // In 0.9.0 one jury serves every item; each judge reads the item's workspace
        // from the JudgmentContext.
        Judge fieldRenamed = context -> {
            try {
                String source = Files.readString(context.workspace().resolve("src/main/java/com/example/Person.java"));
                return source.contains("private final String fullName;")
                        ? Judgment.pass("Field renamed to fullName")
                        : Judgment.fail("Field not renamed");
            }
            catch (IOException e) {
                return Judgment.error("Cannot read Person.java: " + e.getMessage());
            }
        };
        Jury jury = SimpleJury.builder()
            .judge(fieldRenamed, 1.0)
            .votingStrategy(new ConsensusStrategy())
            .build();

        AgentExperiment experiment = new AgentExperiment(new FileSystemDatasetManager(), jury,
                new FileSystemResultStore(results.resolve("results")), config);

        ExperimentResult result = experiment.run(agent);

        result.items().forEach(item -> System.out.println(item.itemId() + " passed=" + item.passed()));
        System.out.printf("Passed %d of %d scored items%n", result.counts().passes(), result.counts().scored());
    }
}
```

Compile and run:

```bash
./mvnw compile
java -cp target/classes:$(./mvnw -q dependency:build-classpath -Dmdep.outputFile=/dev/stdout) \
  com.example.experiment.GettingStarted
```

Output:

```text
RENAME-001 passed=true
Passed 1 of 1 scored items
```

With an agent that changes nothing, the same program prints `RENAME-001 passed=false` and `Passed 0 of 1 scored items`.

**`src/main/java/com/example/experiment/GettingStarted.java`** — on main the experiment takes a function that builds a fresh jury for every item, and a judge is `Judgment judge()` with no context:

```java
package com.example.experiment;

import java.io.IOException;
import java.io.UncheckedIOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.time.Duration;
import java.util.List;

import io.github.markpollack.experiment.agent.AgentInvoker;
import io.github.markpollack.experiment.agent.InvocationResult;
import io.github.markpollack.experiment.dataset.FileSystemDatasetManager;
import io.github.markpollack.experiment.result.ExperimentResult;
import io.github.markpollack.experiment.runner.AgentExperiment;
import io.github.markpollack.experiment.runner.ExperimentConfig;
import io.github.markpollack.experiment.store.FileSystemResultStore;
import io.github.markpollack.judge.judgment.Judgment;
import io.github.markpollack.judge.jury.SimpleJury;
import io.github.markpollack.judge.voting.ConsensusStrategy;

public class GettingStarted {

    public static void main(String[] args) {
        Path results = Path.of("target/experiment");

        // The agent under test. This one edits the workspace directly so the example
        // runs offline; a real invoker calls an agent here.
        AgentInvoker agent = context -> {
            Path person = context.workspacePath().resolve("src/main/java/com/example/Person.java");
            try {
                String source = Files.readString(person);
                Files.writeString(person, source.replace("getName", "getFullName").replace("name", "fullName"));
            }
            catch (IOException e) {
                return InvocationResult.error(e.getMessage(), context.metadata());
            }
            return InvocationResult.completed(List.of(), 0, 0, 0, 0.0, 0, null, context.metadata());
        };

        ExperimentConfig config = ExperimentConfig.builder()
            .experimentName("rename-field-v1")
            .datasetDir(Path.of("my-dataset"))
            .model("offline-example")
            .promptTemplate("{{task}}")
            .perItemTimeout(Duration.ofMinutes(2))
            .outputDir(results.resolve("workspaces"))
            .build();

        // A fresh jury for every item. The input names that item's workspace.
        AgentExperiment experiment = new AgentExperiment(new FileSystemDatasetManager(),
                input -> SimpleJury.builder()
                    .judge("field-renamed", () -> {
                        Path person = input.workspace().resolve("src/main/java/com/example/Person.java");
                        return read(person).contains("private final String fullName;")
                                ? Judgment.pass("Field renamed to fullName")
                                : Judgment.fail("Field not renamed");
                    })
                    .votingStrategy(new ConsensusStrategy())
                    .build(),
                new FileSystemResultStore(results.resolve("results")), config);

        ExperimentResult result = experiment.run(agent);

        result.items().forEach(item -> System.out.println(item.itemId() + " passed=" + item.passed()));
        System.out.printf("Passed %d of %d scored items%n", result.counts().passes(), result.counts().scored());
    }

    private static String read(Path file) {
        try {
            return Files.readString(file);
        }
        catch (IOException e) {
            throw new UncheckedIOException(e);
        }
    }
}
```

Compile, then run with a writer identity. On main `experiment.writer.revision` is **required**: without it the run fails with "Set experiment.writer.revision or supply a writer identity".

```bash
./mvnw compile
java -Dexperiment.writer.revision=my-experiment@local \
  -cp target/classes:$(./mvnw -q dependency:build-classpath -Dmdep.outputFile=/dev/stdout) \
  com.example.experiment.GettingStarted
```

```text
Passed 1 of 1 scored items
```

## Using a real agent

Replace the lambda that edits `Person.java` with your agent.

- **0.9.0:** for Claude Code, use `ClaudeSdkInvoker` from the `experiment-claude` module (0.9.0; removed on main).
- **main:** for Claude Code or Codex, use `AgentClientInvoker` from `experiment-agent-client`, which takes its options from Agent Client.

The [agent-experiment-template](https://github.com/markpollack/agent-experiment-template) is pinned to 0.6.0 and is not yet updated for these versions.

## Compare variants

Same dataset, a different configuration: build one `AgentExperiment` per configuration and run each.

```java
// 0.9.0: each configuration gets its own experiment
AgentExperiment base = new AgentExperiment(datasetManager, jury, resultStore, configA);
ExperimentResult resultA = base.run(baseAgent);

AgentExperiment withKb = new AgentExperiment(datasetManager, jury, resultStore, configB);
ExperimentResult resultB = withKb.run(kbAgent);
```

`configB` can add `.knowledgeBaseDir(Path.of("knowledge"))` and a prompt template that includes `{{knowledgeRefs}}`. Compare the two with `DefaultComparisonEngine`; see [Creating Experiments](/docs/agent-experiment/creating-experiments#cross-run-comparison).
