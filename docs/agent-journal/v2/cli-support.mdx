Support is per CLI and launch route, as recorded in the compatibility registry [`compatibility.json`](https://github.com/markpollack/agent-journal/blob/453c1d1/journal-ocsf-writer/src/main/resources/ocsf/compatibility.json). The table below is generated from that file at `453c1d1`: all 20 entries.

## What the labels mean

| Label | Meaning |
|---|---|
| **admitted** | A production standard-output route whose live captures, sanitized replay fixtures, inventories, dispositions, independent oracle profile, mapping catalog and live-scenario roster are all registered |
| **experimental** | A source route tested on recorded evidence, used as a declared source of a reviewed final-assembly profile or kept for its recordings; not admitted |
| **historical** | A retired route kept so its recordings replay as tested; never extended |

Admission means the route's normalization is exercised on recorded live input and checked by the independent oracle. It is not approval of every meaning: meanings still marked proposed stay proposed, and the output states what the source did not establish rather than guessing it.

## Version rule

Most entries name one exact CLI version. A version-neutral entry (`"versions": "any"`) selects for any CLI version on its route, and the observed version is recorded, not gated. An exact entry wins over a version-neutral one. Input that matches no entry is retained whole under the untested-compatibility contract and flagged; it is never normalized by the nearest entry.

## Known limits

- GitHub Copilot CLI's per-response duration and Junie's per-call time carry no vendor-stated unit.
- Junie's cache counters are reported as zero without establishing whether they are measured, so its uncached input is conditional.
- A Claude Code foreground sub-agent stream that omits one of its messages is not yet detected as incomplete against the vendor's own counts.

Not supported on main: Gemini CLI and Grok CLI capture (the 1.x line has them). Per-CLI support statements live in the repository under [`docs/cli-support`](https://github.com/markpollack/agent-journal/tree/453c1d1/docs/cli-support), for example [Antigravity CLI 1.4.6](https://github.com/markpollack/agent-journal/blob/453c1d1/docs/cli-support/antigravity-cli-1.4.6.md).
