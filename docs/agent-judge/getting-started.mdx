## Build the source artifacts

You need Java 21 and the committed Maven wrapper.
Use an isolated Maven repository and the exact source revision below. Do not consume an arbitrary older snapshot from your normal local repository.
These commands install locally; they do not publish artifacts or integrate producer branches.

```bash
export EVAL_M2="$PWD/eval-m2"
git clone https://github.com/markpollack/agent-judge.git agent-eval-source
cd agent-eval-source
git checkout --detach 9ccddd31862cc79c7dc2b2d41f4fb1596a56972a
./mvnw -nsu -Dmaven.repo.local="$EVAL_M2" -pl agent-judge-ai-core,agent-judge-agent-client,agent-judge-exec,agent-judge-assertj -am -DskipTests clean install
```

The first build downloads dependencies. `-DskipTests` builds artifacts and is not an acceptance-gate result.
Keep that same `EVAL_M2` when compiling callers.
Each caller POM needs its own dependency/plugin preparation before using `-o`; installing the producer alone does not prepare them all.
The [requirements guide](/docs/agent-judge/requirements-judges#run-a-prepared-example) has a complete caller POM and executable Java example with deterministic responses.
No live inference is needed.

## Configure, execute, retain

1. Define or read the actual Requirement and its immutable source/revision.
2. Select prepared evidence, an acquisition supplier, or a native investigative runtime configured with workspace/tools.
3. Construct a ready Judge or Jury using typed builders.
4. Execute `judge()` or `vote()`, or one cached AssertJ stage.
5. Keep the whole result and optionally request an application reliance policy.
6. Store/reopen V6 results with the explicit Jackson support module.

## Dependencies

All source artifacts retain group `io.github.markpollack` and version `0.18.0-SNAPSHOT`.
Declare the source version explicitly; no AgentWorks BOM change is implied.
The inventory is 14 JAR modules plus `agent-judge-parent` (POM packaging).
The [0.18 migration guide](/docs/agent-judge/migration-0.18) explains the intentional API and wire breaks.

| Artifact | Purpose |
|---|---|
| `agent-judge-core` | Pure requirements, Judge/Jury construction, results, voting, policy |
| `agent-judge-ai-core` | EvalModel, native RFC2119/EARS requirements and producers |
| `agent-judge-json-jackson2` | Explicit Jackson 2 converters and strict V6 codecs |
| `agent-judge-assertj` / `agent-judge-assertions` | Fluent assertions / retained assertion checks |
| `agent-judge-llm` / `agent-judge-agent-client` | Generated runtime adapters |
| `agent-judge-jev` | Typed structured native execution |
| `agent-judge-exec` / `agent-judge-file` | Build/command and file evaluation |
| `agent-judge-rag` | Typed retrieval evidence and RAG judges |
| `agent-judge-spring-ai` / `agent-judge-langchain4j` / `agent-judge-koog` | Evaluated response evidence bridges |

The [PetClinic source path](/docs/agent-judge/petclinic-case-study) demonstrates configured 0.18 APIs.
