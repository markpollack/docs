A requirement owns identity, revision, specification, and source. It owns neither evidence nor execution.
`EarsRequirement.from(path, revision)` and `Rfc2119Requirement.from(path, revision)` read the selected document during setup and retain its SHA-256 source reference and native item IDs.
Select your roster before executing. The PetClinic path keeps `UC6-AC7` through `UC6-AC12` (six), the full UC6 document (52), and the architectural MUST roster (13).

| Operation | Construction | Execution result |
|---|---|---|
| One native requirement | `EarsJudge` / `Rfc2119Judge`, `.requirement(actual)` | `judge()` returns `Judgment` |
| Selected native roster | `EarsJury` / `Rfc2119Jury`, `.requirements(roster)` | `vote()` returns complete `Verdict` |
| Prepared generated evidence | `.evidence(text).build()` | Uses supplied evidence; acquisition suppliers run at execution |
| Integrated investigation | `.requirements(roster).build()` | Uses configured backend workspace/tools |
| Structured native runtime | `.runtime(EvalRuntime<RequirementRequest<S,E>,Judgment>)` | Actual typed evidence and per-item native execution |

## Configure the runtime

`EvalModel` specializes `EvalRuntime<EvalModelRequest,EvalModelResponse>` for generated answers.
`SpringAiEvalModel` adapts Spring AI; `AgentClientEvalModel` adapts a native agent client.
Configure credentials, workspace, permissions, tools, deadlines, and native options on the backend before constructing the Judge or Jury.
An investigative harness needs actual investigation capability. A prepared-only harness can declare `withInputs(GeneratedInput.PREPARED_EVIDENCE)`; requesting investigation then fails before calls.
Request roles, options, and metadata must be transmitted honestly or refused before invocation. SDK capture does not promise raw HTTP bytes. Cancellation propagates.

## Invocation counts

A generated investigative roster enters the configured backend **once for the selected whole roster**.
That backend may make several internal model or tool calls. One Agent Eval invocation does not imply one HTTP request, turn, or tool operation.
The root Verdict owns the shared Invocation; each requirement result references its ID rather than repeating its usage.

Structured roster runtimes execute separately for each item: EARS6 means six executions, EARS52 means 52, and RFC13 means 13.
Jev uses this typed path; its per-item counts must not be described as one generated batch call.
`InvocationRecords.of(verdict)` resolves retained owners and counts each ID once, including lower invocations on refused originals.
Unknown usage or cost stays absent; an omitted field is not zero.

## Run a prepared example

This complete example uses synthetic answers and citations to test plumbing. It makes no model call and establishes no claim about the real application.
Create `requirements-demo` beside the producer source checkout. Save the POM below there, and
save the Java block as `requirements-demo/src/main/java/RequirementsDemo.java`. Run the command
from the producer checkout so its committed Maven wrapper is available.

```java
import java.util.List;
import java.util.Map;
import java.util.concurrent.atomic.AtomicInteger;
import io.github.markpollack.judge.ai.model.*;
import io.github.markpollack.judge.ai.requirements.*;
import io.github.markpollack.judge.evaluation.*;
import io.github.markpollack.judge.policy.*;
import io.github.markpollack.judge.verdict.*;
import static io.github.markpollack.judge.assertj.Assertions.assertThat;

public class RequirementsDemo {
    public static void main(String[] args) {
        var first = EarsRequirement.of("UC6-AC7", "fixture-v1", "Cancellation",
            "When an owner cancels before start, the system shall cancel the appointment.", null);
        var second = EarsRequirement.of("UC6-AC8", "fixture-v1", "Boundary",
            "When cancellation is requested at start, the system shall reject it.", null);
        var calls = new AtomicInteger();
        EvalModel runtime = request -> {
            calls.incrementAndGet();
            if (!request.messages().getFirst().content().contains("captured source facts"))
                throw new AssertionError("Evidence was not supplied");
            return new EvalModelResponse("UC6-AC7: PASS - Fixture.java:1\n"
                + "UC6-AC8: CANNOT_DETERMINE - boundary execution absent", "deterministic-fixture",
                null, Map.of("fixture", "requirements-demo"));
        };
        var jury = EarsJury.builder().runtime(runtime).requirements(List.of(first, second))
            .evidence("captured source facts").build();
        var stage = assertThat(jury).withPolicy(whole ->
            new PolicyDecision(PolicyAction.ESCALATE, "Obtain boundary evidence before relying"));
        EvaluationResult result = stage.evaluate();
        var codec = NativeRequirementCodecs.codec();
        EvaluationResult retained = codec.readEvaluation(codec.write(result));
        assertThat(retained).hasConclusion(Verdict.Conclusion.INCONCLUSIVE);
        assertThat(stage.evaluate()).hasConclusion(Verdict.Conclusion.INCONCLUSIVE);
        if (!retained.equals(result) || calls.get() != 1)
            throw new AssertionError("Complete retention or cached execution failed");
        System.out.println("INCONCLUSIVE; roster=" + retained.verdict().roster().size()
            + "; invocations=" + InvocationRecords.of(retained.verdict()).size() + "; calls=" + calls.get());

        EvalModel singleRuntime = request -> new EvalModelResponse("UC6-AC7: PASS - Fixture.java:1",
            "deterministic-fixture", null, Map.of());
        var judge = EarsJudge.builder().runtime(singleRuntime).requirement(first)
            .evidence("captured source facts").build();
        if (judge.judge().requirement() != first) throw new AssertionError("Requirement association lost");
        assertThat(first).judgedBy(EarsJudge.builder().runtime(singleRuntime))
            .withEvidence("captured source facts").isSatisfied();
        System.out.println("Prepared Judge and requirement-first AssertJ: PASS");
    }
}
```

Keep the exact producer revision `0d0abe47b34c0e638e68ed81c5a764d6b424bc86` installed in the same isolated `EVAL_M2`.
Prepare this standalone caller's own dependencies and Maven plugins with a first run without `-o`.
The producer build alone does not download everything in this caller POM.
`-nsu` suppresses snapshot update checks while Maven downloads missing dependencies and plugins.
The example uses deterministic responses and performs no live inference.

```bash
./mvnw -nsu -f ../requirements-demo/pom.xml -Dmaven.repo.local="$EVAL_M2" compile exec:java -Dexec.mainClass=RequirementsDemo
```

Once that preparation succeeds, subsequent runs can use the same isolated repository offline:

```bash
./mvnw -o -f ../requirements-demo/pom.xml -Dmaven.repo.local="$EVAL_M2" compile exec:java -Dexec.mainClass=RequirementsDemo
```

Expected output:

```text
INCONCLUSIVE; roster=2; invocations=1; calls=1
Prepared Judge and requirement-first AssertJ: PASS
```

The roster keeps both actual requirements and both complete item results in `compositeAttempts`.
One ABSTAIN leaves this roster INCONCLUSIVE. A verified violation produces FAIL; omission, malformed identity, or unjustified N/A prevents a passing audit.
Applicability must be declared before execution. An excluded original remains visible with its treatment.
A native roster establishes required coverage; an ordinary voting panel combines opinions. `AllEligiblePassStrategy` is an opinion rule, not a substitute for roster coverage.

## Requirement-first assertions

`assertThat(actualRequirement).judgedBy(recipe).withEvidence(actualEvidence).isSatisfied()` passes the actual Requirement into typed construction.
Ready Judge/Jury assertions use `isPassed()`; `evaluate()` returns the complete reusable `EvaluationResult`.
Repeated terminals on the same live stage cache the result or thrown failure. Calling `judge()` or `vote()` separately is a fresh execution.
Retained assertions inspect Verdict/EvaluationResult and have no `withPolicy` terminal. Explicitly call `Evaluations.apply(retainedVerdict, policy)` only when requesting a new policy decision.
