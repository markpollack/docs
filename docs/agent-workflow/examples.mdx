This tutorial uses the **0.13.0 executable DSL** and deterministic Java Steps.
It makes no provider calls and needs no API key.
0.13.0 is prepared for publication; use its staged artifacts until Maven Central publication is confirmed.
Durable loops, waits/timers and committed-event Journal projection are unavailable in this milestone.

The [existing tutorial repository](https://github.com/markpollack/workflow-dsl-examples/blob/tutorial/workflow-dsl-consolidation-20261008/executable-dsl/README.md) now has a standalone `executable-dsl` progression.
Every lesson contains concrete input/output records, ordinary Step objects, a fluent definition and asserted runtime results.

Run the [tutorial](/docs/agent-workflow/tutorial) command once and then again with the same directory.
The examples use the local JDBC runtime and no provider.
The older root provider comparison reactor remains pinned to its legacy APIs and is not the 0.13.0 authoring path.

The library also retains a [standalone changed-file review example](https://github.com/markpollack/agent-workflow/blob/r1/executable-dsl-release-20261008/examples/review-files/README.md).
The next-version terminal-child completion addition appears separately in the [API reference](/docs/agent-workflow/api-reference).
