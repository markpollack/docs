**[What's New in 0.14 →](/docs/agent-judge/whats-new)**

Agent Judge is a Java 21 evaluation library for deciding whether an agent result satisfies its goal.
It combines deterministic checks, command execution, file comparison, RAG evaluation, LLM-backed assessment, and multi-judge aggregation.

The central result is status-first.
Every `Judgment` has a `PASS`, `FAIL`, `ABSTAIN`, or `ERROR` status, while a normalized score and classification label are independent optional facts.
Result metadata is restricted to portable values so judgments can cross JSON and process boundaries reliably.

## Runtime-neutral evaluation

Spring AI, LangChain4j, Koog, and AgentClient each have their own execution model.
Each Agent Judge bridge converts framework output into a `JudgmentContext`, after which the same judges and juries evaluate it.

| Runtime | Bridge module | Entry point |
|---|---|---|
| Spring AI | `agent-judge-spring-ai` | `SpringAiEvaluator` |
| LangChain4j | `agent-judge-langchain4j` | `LangChain4jEvaluator` |
| Koog | `agent-judge-koog` | `KoogEvaluator` |
| CLI agents | `agent-judge-agent-client` | `AgentClientEvaluator` |

## Ten modules

| Module | Purpose |
|---|---|
| `agent-judge-core` | Core contracts, result model, file checks, juries, and voting strategies |
| `agent-judge-ai-core` | Framework-neutral prompt, model, and classifier composition |
| `agent-judge-exec` | Command, build, class-version, and coverage judges |
| `agent-judge-file` | Java, Maven, XML, and text semantic comparison |
| `agent-judge-llm` | Spring AI judging backend and correctness judge |
| `agent-judge-rag` | Faithfulness, hallucination, and contextual-relevance judges |
| `agent-judge-spring-ai` | Spring AI evaluated-side bridge |
| `agent-judge-langchain4j` | LangChain4j evaluated-side bridge |
| `agent-judge-koog` | Koog evaluated-side bridge |
| `agent-judge-agent-client` | AgentClient evaluated-side bridge and judging backend |

The core is framework-neutral, not dependency-free.
It uses Jackson for its portable result boundary, SLF4J for logging, and JSpecify annotations for nullness declarations.

## Install 0.14

```xml
<dependency>
  <groupId>io.github.markpollack</groupId>
  <artifactId>agent-judge-core</artifactId>
  <version>0.14.0</version>
</dependency>
```

Add only the family and bridge modules that your application uses.
