## Overview

The AgentWorks BOM pins a set of agent engineering library versions that were verified together. Import it once and drop version tags for the artifacts it manages. A released BOM can trail an individual library's newest release: 1.21.0 manages Agent Client 0.31.0, Agent Journal 1.10.1, Agent Workflow 0.12.3, Agent Judge 0.17.0 and the ACP Java SDK 0.17.0. To use a newer release, declare its version explicitly. Modules added after 1.21.0, such as `agent-judge-json-jackson2` and `agent-judge-assertj`, are not managed by 1.21.0.

## Maven

```xml
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>io.github.markpollack</groupId>
            <artifactId>agentworks-bom</artifactId>
            <version>1.21.0</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

<!-- Then just: -->
<dependency>
    <groupId>io.github.markpollack</groupId>
    <artifactId>experiment-core</artifactId>
    <!-- version managed by BOM -->
</dependency>
```

**On main, not yet released (1.22.0-SNAPSHOT).** A development BOM is published to the Central snapshot repository on every push to `markpollack/agentworks` main. It manages the members' development lines (Client 0.32.1-SNAPSHOT, Journal 2.0.0-SNAPSHOT modules, Workflow 0.14.1-SNAPSHOT, Judge 0.19.0-SNAPSHOT, Sandbox 0.11.0-SNAPSHOT, Experiment 0.10.0-SNAPSHOT, Claude Agent SDK 1.8.0-SNAPSHOT) and ACP Java SDK 0.18.0, and adds 24 entries, including the Client lifecycle modules and the Judge assertion and JSON modules. Provenance is the agentworks main commit, currently `1a4f0d4` (build `1.22.0-20261107.204414-2`). See [Using development snapshots from main](/docs/development-snapshots). None of this is in 1.21.0.
